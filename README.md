## Enable free hosting (GitHub Pages) — ~30 seconds

1. Open: https://github.com/stpetepower-afk/h3o-juice/settings/pages  
2. **Source** → Deploy from a branch  
3. Branch: `main` → folder: `/ (root)`  
4. Save  

Site will appear at: **https://stpetepower-afk.github.io/h3o-juice/**
